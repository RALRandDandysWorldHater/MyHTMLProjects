CSS Position Property

Learn how CSS positions elements on a webpage. Scroll through each example and observe what happens.

1. Position: Static

Concept: Static is the default positioning of every HTML element. The element follows the normal document flow. The properties top, right, bottom and left do not move it.
Buddy - Normal element
🐶 Luna - position: static
Max - Normal element

Observe: All three elements appear one after another. Static does not create any special movement.

2. Position: Relative

Concept: Relative moves an element from its original position. However, its original space remains reserved. Other elements behave as if the element is still in its original position.
Buddy - Before relative element
Original position of Daisy would be here.
🐶 Daisy - position: relative
left: 35px;
top: 10px;
Rocky - After relative element

Observe: Daisy moves 35px right and 10px down. But the original space is still occupied. Rocky does not move into that space.

3. Position: Absolute

Concept: Absolute removes an element from normal document flow. It positions itself relative to its nearest positioned ancestor. Here, the pet-card has position: relative.
Buddy - Before the card
PARENT: position: relative

Max - After the card

Observe: The badge is positioned 10px from the card's top and right edges. The badge is not positioned relative to the entire webpage because its parent is positioned.

4. Position: Fixed

Concept: Fixed positions an element relative to the viewport in the usual case. It stays at the same screen position when you scroll. It is removed from normal document flow.
Fixed elements can be useful for floating buttons, chat buttons and navigation bars.

Look at the purple box in the bottom-right corner. Scroll the page up and down. Notice that it remains in the same position.

5. Position: Sticky

Concept: Sticky is a combination of relative and fixed-like scrolling behavior. Initially, it behaves like a normal element. When it reaches top: 65px, it sticks there while scrolling within its scrolling container.

Final Comparison

Position Normal Flow? Moves? Scroll Behavior
