Learn how the five CSS position values work by observing the elements below.

1. Static

Static is the default position of an HTML element. It follows the normal document flow. Top, right, bottom and left have no effect.

2. Relative

Relative moves an element from its original position. Its original space remains reserved.

3. Absolute

Absolute removes an element from normal document flow. It positions itself relative to its nearest positioned ancestor.

4. Fixed

Fixed positions an element relative to the viewport in the usual case. It stays in the same screen position even when you scroll.

Look at the orange navigation bar at the top. Scroll the page and notice that it remains there.

5. Sticky

Sticky initially behaves like a normal element. When it reaches top: 55px, it sticks below the navigation bar while scrolling.
