📱 Lesson 4: Responsive Design

A responsive website adjusts its layout for different screen sizes. Let's imagine that you're viewing your website on different devices.

Preview width: 700px

SIMULATED SCREEN
Remember: This is a visual demonstration. The preview width is controlled by JavaScript. Bootstrap's normal responsive breakpoints are based on the browser viewport, not the width of this preview box.
Try this Bootstrap code:
<div class="row"> <div class="col-12 col-md-6"> First box </div> <div class="col-12 col-md-6"> Second box </div> </div>

What does it mean?

  • row creates a row for the columns.
  • col-12 makes a box full-width on smaller screens.
  • col-md-6 makes each box half-width at Bootstrap's medium breakpoint and above.

Bootstrap 5 uses a medium breakpoint of 768px by default.

🧩 Lesson 5: Understand the Three Magic Words

1. container

A container keeps your content organized and provides a suitable width for the page.

<div class="container"> My website content </div>
2. row

A row holds your columns together.

<div class="row"> My columns go here </div>
3. col

A col is a column inside a row. For example, col-6 uses half of the 12-column grid.

<div class="row"> <div class="col-6">Left</div> <div class="col-6">Right</div> </div>
